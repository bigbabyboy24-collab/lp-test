# lp-test

ニホンバシブルワリー 池袋店（NIHONBASHI BREWERY. 池袋店）のランディングページ。

静的な HTML / CSS / JavaScript のみで構成されています。ビルド不要です。

## 表示方法

`index.html` をブラウザで直接開くだけで表示できます。

ローカルサーバーで確認する場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 構成

```
.
├── index.html          # ページ本体
├── css/style.css       # スタイル（デザイントークンは :root にまとめています）
├── js/main.js          # モバイルメニュー / 固定CTA / スクロール表示
└── images/             # 店舗の実写11点（Web用に最適化済み・計約1.7MB）
    └── README.md       # 各写真の使用箇所と元ファイルの対応表
```

## セクション構成

ファーストビュー → コンセプト → クラフトビール → お料理 → ランチ →
利用シーン → 店内 → ご宴会・貸切 → 店舗情報・アクセス

## デザイン

「木の温もりを活かした洗練されたデザイン」という実店舗の内装に合わせた
ライト×ナチュラル方向。配色は `css/style.css` 冒頭の `:root` で一括変更できます。

| 変数 | 用途 |
|---|---|
| `--cream` / `--cream-deep` | 背景 |
| `--wood` / `--wood-deep` | 罫線・面のアクセント |
| `--ink` / `--ink-soft` / `--ink-mute` | テキスト |
| `--terra` | メインアクセント（CTA・見出しラベル） |
| `--gold` | ビールの琥珀色 |

## 掲載情報について

本文の店舗情報は、運営元である株式会社ZOT のプレスリリースおよび
各種掲載記事をもとにしています（2025年2月オープン時点）。

**公開前に、以下は必ず店舗ご担当者に最新の内容をご確認ください。**

- 営業時間・定休日・ラストオーダー
- 電話番号、予約手段（電話以外の予約導線を追加するか）
- 提供中のクラフトビールの種類数（12種と記載しています）
- メニュー名・価格（価格は意図的に未掲載です）
- ランチの特典内容（スムージー・サラダのおかわり自由）
- 貸切の最大人数（50名と記載しています）

## 写真について

`~/LP/写真一覧` の店舗写真86枚から選定し、リサイズ・EXIF除去・圧縮したものを
`images/` に配置しています。対応表は `images/README.md` を参照してください。
差し替えは同名ファイルの上書きだけで反映されます。
