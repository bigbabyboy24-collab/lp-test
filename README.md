公開URL: https://bigbabyboy24-collab.github.io/lp-test/

## 表示方法

`index.html` をブラウザで直接開くだけで表示できます。

## デザイン

配色は `index.html` 冒頭の `:root` で一括変更できます。
アクセントは1色（`--accent`）のみで、ほかはすべてニュートラルです。

| 変数 | 用途 |
|---|---|
| `--bg` / `--bg-deep` / `--surface` | 背景・カード面 |
| `--line` | 罫線 |
| `--ink` / `--ink-2` / `--ink-3` | テキスト（濃 → 淡） |
| `--accent` / `--accent-deep` / `--accent-tint` | CTA・英字ラベル・リンク |
| `--dark` / `--dark-2` | ヒーロー・フッターの暗部 |

本文色はいずれも背景に対してコントラスト比 4.5:1 以上（WCAG AA）を満たしています。
`--accent` を変更する場合は、`--bg`・`--bg-deep`・`--surface` の3つの背景と、
白文字を乗せた場合の4通りで比率を再確認してください。

## 掲載情報について

本文の店舗情報は、オープン時のプレスリリースおよび各種掲載記事をもとにしています。
**掲載当時の情報のため、現在の内容と異なる可能性があります。**

なお、運営会社名および開店年月は、ページに掲載しない方針です。
文言を追記する際も、これらを含めないようご注意ください。

**公開前に、以下は必ず店舗ご担当者に最新の内容をご確認ください。**

- 営業時間・定休日・ラストオーダー
- 電話番号、予約手段
- 提供中のクラフトビールの種類数（12種と記載しています）
- メニュー名（価格は意図的に未掲載です）
- ランチの特典内容（スムージー・サラダのおかわり自由）
- 貸切の最大人数（50名と記載しています）
- **予算目安（ランチ ¥1,000〜／ディナー ¥3,000〜 は仮の数値です）**
  変更する場合は次の3箇所すべてを更新してください:
  1. Lunch セクションの `.budget` ブロック
  2. Information セクションの「予算目安」行
  3. `<head>` 内 JSON-LD の `priceRange`
- **JSON-LD の `geo`（緯度経度）は住所からの概算値です**

## 口コミの扱い

**Google マップ・食べログいずれも、口コミ本文はこのページに転載していません。**
各サイトへのリンクから誘導する構成です。

理由:

- 口コミのコピー転載は、各サービスの利用規約および投稿者本人の著作権に抵触します
- Google マップは JavaScript で描画されるため、そもそも自動取得もできません

リンク先:

- Google マップ（検索リンク）
- 食べログ: https://tabelog.com/tokyo/A1305/A130501/13305524/

将来的に口コミ本文を掲載する場合は、次のいずれかの方法をとってください。

1. **Google Places API (New) の Place Details** で `reviews` を取得し、
   ページ読み込み時に表示する。投稿者名・投稿時期・Googleへの帰属表示が必須で、
   取得したデータを30日を超えてキャッシュすることはできません。
   ブラウザから呼ぶ場合はAPIキーにHTTPリファラー制限をかけてください
2. **投稿者本人から個別に許諾を得て**、出典を明記して掲載する

いずれの場合も、**架空のレビューを作成してはいけません**。
景品表示法のステルスマーケティング規制に抵触します。
