# images ディレクトリ

このLPは **写真がなくても成立する**ように作られています。
各セクションの画像は CSS の `background-image` で「写真 → グラデーション」の順に
重ねてあるため、ファイルが無い場合は自動的にグラデーションが表示されます。

下記のファイル名で写真を置くだけで、コードを変更せずに反映されます。

| ファイル名 | 使用箇所 | 推奨サイズ | 備考 |
|---|---|---|---|
| `hero.jpg` | ファーストビュー背景 | 2000 × 1200px 以上 | 店内かビールの引き画。左側に文字が乗るので、被写体は右寄りが◎ |
| `prosciutto.jpg` | 生ハムビスマルク | 1200 × 900px | 横長で使用 |
| `pasta.jpg` | ウニクリームパスタ | 1200 × 900px | |
| `genovese.jpg` | ジェノベーゼ（ホタテ・エビ・スダチ） | 1200 × 900px | |
| `pudding.jpg` | 自家製プリン | 1200 × 900px | |
| `lunch.jpg` | ランチセクション | 1200 × 1000px | 縦長寄りで使用 |

## 注意

- ファイル形式は `.jpg` を前提にしています。`.webp` などを使う場合は
  `css/style.css` 内の `url("../images/xxx.jpg")` を書き換えてください。
- 1枚あたり 300KB 程度まで圧縮しておくと表示が軽くなります。
- 店舗の実写を使用してください。他店・フリー素材の料理写真を使うと
  景品表示法上の問題になる可能性があります。
