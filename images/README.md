## 差し替えかた

同じファイル名で上書きするだけで反映されます。HTML・CSS の変更は不要です。

推奨のトリミング比率:

- `hero.jpg` … 5:3（横長）。左半分にテキストが乗るため、主役は右寄りが理想
- `beer-band.jpg` … 約 8:3（帯）
- 料理写真 … 4:3
- `lunch.jpg` … 6:5（やや縦長）
- `interior-*.jpg` … 9:7

## 注意

- 写真が無い場合でもグラデーションで代替表示されるため、レイアウトは崩れません。
- 1枚 300KB 以下を目安にしてください。
- 掲載しているのはすべて店舗の実写です。他店・フリー素材の料理写真に
  差し替えると景品表示法上の問題になる可能性があります。
